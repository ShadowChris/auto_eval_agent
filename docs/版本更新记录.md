# 版本更新记录

记录每个留档版本相对上一版本的主要功能变化，最新版本放在最上面。
后续只需补充版本号、日期、留档分支，以及“新增 / 调整 / 修复 / 升级注意”，没有内容的分类不写。
本文件统一以 `main` 为准维护，文档更新同步到 `dev`、`dev_czm`；不在各条 release 分支分别维护。
留档从实际确认的代码提交创建，不必为了留档先把 `dev` 合入 `main`；已留档分支不再跟进日常开发。
旧版本留档之后补充文档，无需重新创建或移动原留档分支；后续新版本留档前先整理对应的更新记录。

## v0.1 — 2026-11-14

- **留档分支**：`release/v0.1`
- **代码基线**：当时的 `main`，提交 [`90c4493`](https://github.com/ShadowChris/auto_eval_agent/commit/90c4493bf08c8aab199ce6c8be445db4404084b7)。
- **版本说明**：大改前首次留档，没有上一留档版本。以下为已有核心能力摘要，不代表本次新增。

### 已有核心能力

- **任务类录屏评估**：结合 Query、可选 Context、用户图片、录屏关键帧与 Agent 自述，由终端用户裁判输出判定、维度分数、理由及问题/复核类别。
- **数据集输入**：支持 JSONL、CSV、Excel 导入预览，保留原始附加字段，支持视频起止时间和附件图片地址。
- **批跑管理**：支持并发和请求限速、后台运行、历史记录、失败/选中项重跑，以及历史评估集追加与修订。
- **统计与对比**：支持单批报告、历史及上传结果集对比、问题类型与复核类别分析。
- **结果导出与部署**：支持 Excel、JSONL、HTML 等结果导出、录屏抽帧 ZIP，以及 Linux systemd 部署模板。

- 只包含上述基线提交中的已跟踪文件，不包含开发分支后续改动、未提交修改、`.env`、本地数据集或运行结果。
- 本次只建立代码留档，不修改评估逻辑，不需要重启服务或迁移历史数据。
