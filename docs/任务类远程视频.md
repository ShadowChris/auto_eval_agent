# 任务类远程视频输入

任务类单组与多组输入的 `video_path` 同时接受本地路径和 HTTP/HTTPS 视频直链。
Excel/CSV/JSONL 规则相同；导入时保留原链接，不联网下载，也不提示本地视频缺失。
`obs://` 地址、网页分享页、需要网页登录的地址不属于视频直链。

## 执行与生命周期

点击开始评估后，在视频准备阶段下载远程原视频，完成本地探测和抽帧后即删除原视频，
再调用模型。准备失败也删除临时文件；帧图片和评估结果按原链路保存。
临时目录为 `runs/downloads/video_<随机标识>/`，写入先使用 `video.part`，
下载完整后改名为 `video.mp4`（视频真实格式仍由 FFmpeg 探测）。不共享或长期缓存原视频。
已有抽帧的单题重跑仍复用帧；没有有效帧时重新访问原链接。

服务启动时回收超过 24 小时的本功能临时目录，不清理用户本地视频、抽帧或历史。
异步准备取消时通知下载线程停止；正在阻塞的网络读取会在读取超时内返回并清理。
进程被强杀、断电时，残留由下次启动清理。

## 配置与访问边界

`config/remote_video.yaml` 独立配置，不改变模型并发或抽帧算法：

| 配置 | 默认值 |
| --- | --- |
| `download_concurrency` | 每进程最多 10 个下载 |
| `connect_timeout_s` | 10 秒 |
| `read_timeout_s` | 30 秒 |
| `total_timeout_s` | 120 秒下载预算，逐次请求和收到数据时检查 |
| `max_size_mb` | 500 MiB |
| `max_redirects` | 5 次 |
| `max_attempts` | 3 次，含首次；仅网络错误和可重试 HTTP 状态重试 |
| `retry_delay_s` | 基础等待 1 秒，指数退避 |
| `stale_after_hours` | 24 小时 |
| `allowed_hosts` | 默认空；显式列出可访问内网的 OBS 主机 |

默认只访问公网 IP，逐跳校验重定向；连接固定到已校验 IP，HTTPS 保留原主机名进行
证书校验，避免域名二次解析绕过。下载不使用环境代理。私有网络 OBS 需由管理员在
`allowed_hosts` 明确配置主机名；不提供用户密码输入或 OBS SDK 鉴权，私有对象使用签名 HTTPS 链接。
签名查询参数不写入下载错误日志，但作为原始输入保留在历史与导出中，请注意导出文件权限。
网络读取阻塞时仍受单次读取超时约束；视频准备外层继续受现有 `video_prepare_timeout_s` 约束。

## 失败、历史和导出

HTTP 403/404、连接或读取超时、超出大小、空文件、返回网页、无效视频等，按单题
视频准备失败记录 `error`，不调用模型，不生成 `nok` 判定；其他题继续评估。
原始 `video_path`、任意输入字段和签名参数保留；远程视频的“录屏项目相对路径”为空。
抽帧元数据的 video 字段保留原 URL，不指向已经删除的临时文件。

本地原视频仍可下载；远程视频显示“打开链接”，新窗口访问原 URL。兼容原有
`format=video` 接口，远程视频返回 307 重定向，多组可传 `group_index`。
远程链接失效或签名过期后，不能依赖本平台恢复原视频，需要上游提供新的可访问链接。
