# 任务类单题评测接口

> 最后更新：2026-08-20
> 当前仅支持任务类（录屏），固定使用终端用户裁判。

## 1. 单题评测接口

```http
POST /api/eval/single
Content-Type: application/json
```

本地默认地址：`http://localhost:8502/api/eval/single`

### 1.1 Request

#### 顶层字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| `task_id` | string | 是 | 数据集唯一标识。仅支持 1～128 位字母、数字、下划线和连字符，首位必须是字母或数字。 |
| `dataset_name` | string | 否 | Web 历史记录中展示的数据集名称。新建数据集且未传时使用 `task_id`；已有数据集且未传时保留原名称。 |
| `item` | object | 是 | 本次新增或重跑的一道题。 |

#### `item` 字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| `id` | string | 是 | 数据集内唯一题目标识，不能为空，最长 256 个字符。 |
| `query` | string | 是 | 待评估的用户操作意图，不能为空。 |
| `video_path` | string | 是 | 录屏路径，推荐使用项目相对路径。 |
| `context` | string | 否 | Query 的可信背景补充；空字符串按未提供处理。 |
| `answer` | string | 否 | Agent 自述或最终文字回复；也兼容 `agent_statement`。 |
| `task_start_time` | number | 否 | 任务开始时间，单位为秒，必须大于等于 0；默认 7 秒。 |
| `task_end_time` | number | 否 | 任务结束时间，单位为秒，必须大于 `task_start_time`；未传时使用自动结束策略。 |
| 其他字段 | JSON 任意类型 | 否 | 原样保存在 `source_data`，后续历史查看和数据集导出时继续保留。 |

请求示例：

```json
{
  "task_id": "operation_20260820_001",
  "dataset_name": "任务类接口测试集",
  "item": {
    "id": "simple_001",
    "query": "关闭定位",
    "context": "当前设备为测试手机",
    "answer": "已帮你关闭定位",
    "task_start_time": 1,
    "task_end_time": 12.5,
    "video_path": "data/videos/simple_001.mp4",
    "session_id": "session-001",
    "分享链接": "https://example.com/share/001"
  }
}
```

### 1.2 Response

请求受理成功返回 HTTP `202 Accepted`：

```json
{
  "task_id": "operation_20260820_001",
  "id": "simple_001",
  "status": "success",
  "evaluation_status": "running",
  "action": "created",
  "dataset_size": 1
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `task_id` | string | 数据集 ID。 |
| `id` | string | 本次提交的题目 ID。 |
| `status` | string | 请求受理状态；成功值为 `success`。 |
| `evaluation_status` | string | 返回时的数据集评估状态，当前为 `running`。 |
| `action` | string | `created`：创建数据集；`appended`：追加新题；`overwritten`：覆盖并重跑已有题目。 |
| `dataset_size` | integer | 当前数据集题目总数。 |

错误响应格式：

```json
{
  "detail": "具体错误信息"
}
```

| HTTP 状态码 | 说明 |
|---:|---|
| `202` | 请求已受理，后台开始或等待评估。 |
| `409` | 同一题仍在评估；数据集正在执行 Web 批跑或普通重跑；`task_id` 已属于其他评测模式。 |
| `422` | `task_id`、`item.id`、`query`、`video_path`、`context` 或时间字段不符合要求。 |
| `500` | 缺少终端用户裁判配置，或历史快照保存失败。 |

### 1.3 接口注意事项

- 相同 `task_id` 的题目归入同一份 Web 历史数据集，`task_id + item.id` 唯一标识其中一道题。
- 相同数据集的不同 `item.id` 可以并行；当前最多并发 15 条，超出后排队。可在 `.env` 中通过 `AUTO_EVAL_SINGLE_CONCURRENCY` 调整（范围 1～100），修改后需重启服务生效。
- 相同 `task_id + item.id` 在排队或运行期间再次提交会返回 `409`。
- 已完成的相同 `task_id + item.id` 再次提交时，使用新 `item` 整体覆盖旧输入并只重跑该题，其他题目不受影响。
- 当前结果只保留最新版；重跑摘要和模型调用仍沿用 `rerun_history`、`attempt_id`、`attempt_no` 和 `judge_calls*.jsonl` 记录。
- POST 返回 `202` 只表示请求已受理，不表示视频处理或模型评估已经成功。
- 视频不存在、抽帧失败或模型调用失败等后台错误，会显示在对应题目的 Web 进度和结果中。
- 相对视频路径以项目根目录为基准；外部绝对路径需要通过 `OPERATION_VIDEO_ROOTS` 授权。支持 `.mp4`、`.mov`、`.m4v`、`.webm`、`.mkv`、`.avi`。
- Web 历史记录可按 `dataset_name` 或 `task_id` 加载数据集，查看总体进度、单题进度和最新结果；接口数据集按 `item.id` 自然升序展示。
- 当前不提供 Webhook 和接口级单题取消能力。
- 当前接口没有单独鉴权；跨机器或公网部署时，应通过网关、反向代理或网络访问控制限制调用来源。

## 2. 单题结果查询接口

```http
GET /api/eval/single?task_id={task_id}&id={id}&event=0
```

示例：

```text
http://localhost:8502/api/eval/single?task_id=operation_20260820_001&id=simple_001&event=-1
```

### 2.1 Request

| 参数 | 位置 | 类型 | 必填 | 说明 |
|---|---|---|---:|---|
| `task_id` | Query | string | 是 | 数据集 ID。 |
| `id` | Query | string | 是 | 数据集内题目 ID。 |
| `event` | Query | integer | 否 | 日志返回方式，默认 `0`。 |

`event` 规则：

| 值 | 说明 |
|---:|---|
| `0` | 不返回 `progress_events` 字段。 |
| `-1` | 返回当前保留的全部日志。 |
| `n > 0` | 按时间顺序返回前 n 条日志；不足 n 条时返回全部。 |
| `< -1` | 返回 HTTP `422`。 |

当前每题最多保留 100 条 Web 日志，因此 `event=-1` 表示返回当前仍保留的全部日志。

### 2.2 Response

题目存在时返回 HTTP `200`：


`evaluation_status` 取值：

| 值 | 说明 |
|---|---|
| `pending` | 等待评估。 |
| `running` | 正在校验视频、抽帧或调用裁判。 |
| `succeeded` | 评估完成。 |
| `failed` | 视频处理、抽帧或模型评估失败。 |
| `cancelled` | 数据集被中断。 |

`result` 复用当前任务类 Excel“逐题结果”的字段名称、链路中文映射和列表分隔格式。`route_evidence` 是唯一的 JSON 类型差异：接口返回原生数组，Excel 单元格仍保存为 JSON 字符串。

### 2.3 接口注意事项

- `event=0` 时响应中完全不包含 `progress_events`；`event=-1` 或正整数时才返回。
- `progress_events` 与 Web 流式日志使用同一份数据，按 `sequence` 的现有顺序返回。
- `链路类型` 映射为：`fast_system → 快系统`、`skill → skill`、`jarvis → 贾维斯`、`other → 其他`。
- `route_evidence` 中同时返回机器值 `route` 和展示值 `route_name`；没有证据时返回空数组 `[]`。
- `pending`、`running`、`failed` 也返回 Excel 映射后的 `result` 行；尚未生成的评估字段为空。
- GET 只返回该题当前最新输入和最新结果，不返回历史版本或模型原始输出。
- 数据集或题目不存在时返回 HTTP `404`；`task_id` 属于其他评测模式时返回 HTTP `409`。
