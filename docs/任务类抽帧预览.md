# 任务类抽帧预览

结果表的“抽帧结果”列同时提供“预览”和原有 ZIP 下载，不改变抽帧或评估语义。
预览读取已保存在历史里的帧路径，适用于旧历史，也适用于单题失败但已生成帧的记录。
它与远程视频获取无依赖，不会重新抽帧或重新调用模型。

## 交互

点击“预览”打开原生模态弹窗，显示题号、Query、总帧数和当前帧数。
大图下方为可横向滚动的缩略图，点击缩略图可直接跳转；左右按钮和键盘方向键
循环切帧，Esc、关闭按钮或点击遮罩关闭。存在 keyframes.json 时展示采样时间；
旧历史没有元数据时显示“时间未知”。多组任务可切换数据组，帧和时间不跨组混用。
没有帧、帧文件已被清理、网络加载失败均有独立提示。

只有点击预览才请求该题的帧清单；不在结果表批量加载全部图片或 Base64。
缩略图按需加载，由服务端缩小后响应；当前大图单独读取原始抽帧文件。
关闭弹窗或切换题目会取消列表请求、释放组件中的帧清单和图片 DOM。
图片缓存带文件修改时间版本，重新抽帧后再次打开会读取新版本。

## 接口

- `GET /api/eval/{task_id}/items/{item_index}/frames`：该题的分组帧清单及计数。
- `GET /api/eval/{task_id}/items/{item_index}/frames/{frame_index}?group_index=0`：指定帧大图。
- 在图片地址后追加 `thumbnail=true`：最长边不超过 144 像素的 JPEG 缩略图。

只允许访问该题历史中登记、且位于服务运行目录内的图片文件，不接受任意文件路径。
越界索引、越权目录和指向目录外的软链接返回 404；保留原始帧序号，不静默删掉缺失帧。
